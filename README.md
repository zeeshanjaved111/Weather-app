# Weather App 🌤️

A simple and minimal weather application built using **HTML, CSS, and JavaScript**.  
This is the first minimal version of the project, created to practice frontend development and working with weather data.

## 🚀 Live Demo

You can view the live website here:

🔗 https://zeeshanjaved111.github.io/Weather-app/

## ✨ Features

- 🌡️ Displays current weather with temperature, feels-like, humidity
- 💨 Wind speed & direction
- ☀️ UV Index with health level indicator
- 🌅 Sunrise & Sunset times
- 👁️ Visibility & Cloudiness
- 📊 Atmospheric pressure
- 🔍 Search any Pakistan city (auto-complete via Open-Meteo)
- 📅 7-Day forecast with hourly detail (click any day)
- 🌙 Dark/Light mode toggle (saved to localStorage)
- ⚡ Auto-refresh every 3 minutes
- 📱 Fully responsive design
- 🚀 No API key needed (uses Open-Meteo free API)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
